# SyntaxWear - Tênis e Sneakers Online 👟

A **SyntaxWear** é uma loja virtual (e-commerce) moderna e responsiva focada na venda de calçados de alta performance e estilo, como sneakers e tênis casuais. O projeto foi desenvolvido com foco em acessibilidade, semântica HTML e as melhores práticas de CSS moderno.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estrutura semântica para melhor SEO e acessibilidade.
- **CSS3:** Estilização avançada utilizando:
  - **Flexbox:** Para alinhamentos e layouts responsivos.
  - **Unidades Relativas (`rem`, `em`):** Garantindo que o layout se ajuste às preferências do usuário.
  - **CSS Variables:** Para manutenção facilitada de cores e espaçamentos.
  - **Metodologia de Componentes:** Organização do CSS por arquivos específicos para cada parte do site (Header, Footer, Hero, etc.).

## 📱 Funcionalidades

- **Menu Responsivo:** Menu lateral (drawer) que aparece em dispositivos móveis.
- **Seção Hero:** Destaque para os principais lançamentos com chamadas para ação (CTA).
- **Categorização de Produtos:** Divisão visual entre estilos (Casual, Esporte, Moderno).
- **Grid de Produtos:** Exibição organizada dos modelos disponíveis.
- **Newsletter:** Área de captura de e-mails integrada ao rodapé.
- **Social Media:** Links rápidos para as redes sociais da marca.

## 📂 Estrutura do Projeto

```text
ecommerce-syntaxwear/
├── index.html          # Página principal do site
├── css/                # Pasta de estilos
│   ├── base.css        # Estilos globais e reset
│   ├── variables.css   # Definição de cores e fontes
│   └── components/     # Estilos específicos por componente
│       ├── header.css
│       ├── footer.css
│       ├── hero.css
│       └── product-grid.css
└── images/             # Ativos visuais
    ├── logo/           # Identidade visual
    ├── icons/          # Ícones de interface (SVG)
    └── products/       # Fotos dos calçados
```

## 🎨 Design System

O projeto utiliza uma paleta de cores moderna:
- **Cor Primária:** `#7c3aed` (Roxo Vibrante para destaques e hover).
- **Fundo:** `#ffffff` e `#f8f8f8`.
- **Texto:** `#333333` para leitura clara.

## 🔧 Como Visualizar

1. Clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Para uma melhor experiência de desenvolvimento, utilize a extensão **Live Server** no VS Code.
